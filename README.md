# Job Tracker

채용 지원 현황을 한곳에서 관리하는 웹 서비스

## 만든 이유

스프레드시트로 50곳 넘는 지원 현황을 관리하면서 아래와 같은 불편을 겪었다.

- 마감일 형식이 제각각이라 마감순 정렬이나 임박 알림을 쓸 수 없음
- 지원 상태를 한눈에 보기 어려움
- 이번 주에 몇 곳 지원했는지 바로 알 수 없음
- 지원 경로(채용 사이트, 홈페이지 등)별로 모아보기 어려움

## 주요 기능 (예정)

- 지원 상태별 칸반 보드 (지원 전 → 서류 → 과제 → 면접 → 결과)
- 마감일 관리 및 마감 임박 표시
- 지원 경로·상태별 필터
- 주간 지원 수 통계
- 지원 기준 체크 (기술 스택, 근무 형태, 팀 규모 등)
